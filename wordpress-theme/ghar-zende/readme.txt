=== غار زنده ===

قالب اختصاصی وب‌سایت «غار زنده»، بازسازی‌شده به‌صورت کامل به PHP از نسخه‌ی
اصلی Next.js/React همین پروژه.

== ساختار ==

* front-page.php          صفحه‌ی اصلی — نه صحنه‌ی سینمایی اسکرول‌محور
* archive-cave_article.php صفحه‌ی مجله خبری (/magazine/)
* single-cave_article.php  صفحه‌ی هر مقاله
* header.php / footer.php  هدر و فوتر مشترک تمام صفحات
* 404.php / page.php / index.php  قالب‌های عمومی
* inc/cpt-articles.php     نوع پست سفارشی cave_article
* inc/helpers.php          تبدیل تاریخ جلالی، تخمین زمان مطالعه، نویسنده بر اساس دسته
* inc/importer.php         وارد کردن خودکار ۲۴ مقاله واقعی هنگام فعال‌سازی قالب
* inc/nav-walker.php       نمایش منوی وردپرس به‌صورت لینک‌های ساده (بدون ul/li)، هماهنگ با ظاهر اصلی
* assets/css/theme.css     خروجی کامپایل‌شده‌ی Tailwind از ساخت اصلی Next.js
* assets/js/theme.js       تم روشن/تاریک، هدر، منوی موبایل، مکان‌نما، نوار پیشرفت اسکرول
* assets/js/home.js        جلوه‌های GSAP/ScrollTrigger صفحه‌ی اصلی
* assets/js/magazine.js    اسلایدر، کاروسل و اسکرول بی‌نهایت صفحه‌ی مجله
* assets/js/article.js     فهرست مطالب (TOC) و دکمه‌ی کپی لینک

== نصب ==

۱. پوشه‌ی ghar-zende را در wp-content/themes/ کپی کنید.
۲. از بخش «نمایش ← قالب‌ها» آن را فعال کنید — این کار به‌صورت خودکار
   ۲۴ مقاله‌ی واقعی و ۱۳ عکس غار را وارد می‌کند (فقط یک‌بار، در صورت
   نبودن مقاله‌ی قبلی).
۳. از «نمایش ← منوها» یک منوی اصلی بسازید و آن را به موقعیت «منوی اصلی»
   اختصاص دهید؛ در غیر این صورت منوی پیش‌فرض (لنگرهای صفحه‌ی اصلی +
   مجله خبری) نمایش داده می‌شود. برای این‌که یکی از آیتم‌های منو به‌شکل
   دکمه‌ی برجسته («برنامه بازدید» در طرح اصلی) نمایش داده شود: در همان
   صفحه، از «گزینه‌های نمایشگر» بالای صفحه تیک «کلاس‌های CSS» را بزنید،
   آیتم مورد نظر را باز کنید و در فیلد «کلاس‌های CSS (اختیاری)» مقدار
   nav-cta را وارد کنید.

== محدودیت شناخته‌شده ==

این قالب در محیطی بدون نصب واقعی وردپرس/MySQL نوشته و فقط با php -l
اعتبارسنجی نحوی شده است؛ پیش از استفاده‌ی نهایی، آن را روی یک نصب واقعی
وردپرس آزمایش کنید.
