# Cave Aquarium — Reference Images

این پوشه برای نگه‌داری عکس‌های مرجع (رفرنس) پروژه غار/آکواریوم صخره‌ای است.

## نحوه آپلود

عکس‌ها را مستقیماً از طریق GitHub (Add file → Upload files) در همین مسیر آپلود کنید:

```
assets/images/cave-aquarium/
```

فرمت‌های مجاز: `.jpg`, `.jpeg`, `.png`, `.webp`

بعد از آپلود و push شدن عکس‌ها، از اسکیل `ui-ux-pro-max` برای طراحی رابط کاربری بر اساس این تصاویر مرجع استفاده خواهد شد.
